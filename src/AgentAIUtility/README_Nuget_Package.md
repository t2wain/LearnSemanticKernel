# Nuget Packages - Top Level

Microsoft is continuously enhancing these libraries and sometime these libraries are clashing with one another due to bugs in some AI features. Below are combinations of top-level Nuget packages and their versions. Examples within various projects seem to run effective for these combinations of package versions.
